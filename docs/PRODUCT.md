# 🚀 Paylix - Documentation Produit

## Présentation de Paylix
Paylix est un SaaS (Software as a Service) de gestion financière scolaire. Il permet aux établissements scolaires de numériser, suivre et gérer avec précision toutes leurs opérations financières quotidiennes impliquant les élèves, les parents et la comptabilité.

## Problème résolu
De nombreuses écoles gèrent encore leurs finances sur des fichiers Excel, des cahiers ou des systèmes obsolètes. Cela entraîne des erreurs de saisie, des pertes de reçus, une mauvaise visibilité sur les impayés, et une communication difficile avec les parents. Paylix centralise et sécurise ces données dans une plateforme cloud moderne, transparente et multi-tenant.

## Ce que Paylix n'est PAS
**⚠️ Paylix n'est pas une passerelle de paiement en ligne.**
Le parent ne paie pas directement via Paylix (pas de saisie de carte bancaire ou d'intégration de paiement direct dans l'app).

Le flux officiel est le suivant :
1. Le parent paie l'école en dehors de Paylix (banque, espèces, mobile money externe).
2. Le comptable reçoit le paiement ou la preuve de paiement.
3. Le comptable enregistre le paiement dans Paylix.
4. Paylix met à jour les obligations financières.
5. Un reçu est généré.
6. Le parent consulte sa situation mise à jour sur son portail.

*Ne jamais transformer Paylix en système de paiement en ligne sans décision explicite et officielle ultérieure.*

## Utilisateurs cibles
L'application cible quatre types d'utilisateurs distincts :
1. **Platform Admin** : Administrateur global du SaaS Paylix.
2. **Director** : Le directeur qui gère un établissement scolaire.
3. **Accountant** : Le comptable qui gère les opérations financières quotidiennes.
4. **Parent** : Le parent d'élève qui suit la situation financière de ses enfants.

## Fonctionnement général
* Chaque école est un tenant isolé.
* Le directeur configure l'établissement (année scolaire, classes, élèves, frais).
* Le système gère les obligations financières (ce que l'élève doit).
* Les comptables enregistrent les paiements, y compris partiels, et allouent ces montants aux différentes obligations.
* Les parents se connectent sur un espace restreint pour consulter les obligations, les montants payés, les restes à payer, les historiques et les reçus.

## Limites du produit
* **Pas de gestion pédagogique** : Paylix ne gère pas les notes, bulletins, ou présences.
* **Pas de paiement en ligne** : Aucune transaction financière réelle n'est traitée par les serveurs de Paylix.
* **Pas de comptabilité générale complète** : Paylix se concentre sur les frais scolaires, pas sur les bilans de l'entreprise ou les salaires des professeurs.

## Vision générale
Devenir l'outil de référence absolu pour la gestion financière des établissements scolaires, en garantissant une traçabilité totale, une fiabilité sans faille et une architecture robuste.
